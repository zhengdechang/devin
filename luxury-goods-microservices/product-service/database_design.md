# Product Service Database Design

## Product Table (`Product`)
- `product_id`: PRIMARY KEY
- `title`: VARCHAR(255)
- `description`: TEXT
- `images`: JSON/TEXT (Consider storing URLs or references to an image storage service)
- `price`: DECIMAL(10, 2)
- `sku_ref_id`: VARCHAR(255) (标品id)
- `status`: ENUM ('draft', 'listed', 'locked', 'sold')
- `merchant_id`: BIGINT, FOREIGN KEY (references Merchant.merchant_id)
- `ai_enriched`: BOOLEAN DEFAULT FALSE

## Product AI Tags Table (`Product_AI_Tags`)
- `product_id`: BIGINT, FOREIGN KEY (references Product.product_id)
- `tags`: JSON/TEXT (Storing tags generated by AI)
- `created_time`: TIMESTAMP DEFAULT CURRENT_TIMESTAMP

## Product AI Descriptions Table (`Product_AI_Descriptions`)
- `product_id`: BIGINT, FOREIGN KEY (references Product.product_id)
- `language`: VARCHAR(2) (e.g., "en", "ja")
- `description`: TEXT (Storing AI-generated descriptions in different languages)
- `created_time`: TIMESTAMP DEFAULT CURRENT_TIMESTAMP
- PRIMARY KEY (`product_id`, `language`)

## Merchant Table (`Merchant`)
- `merchant_id`: BIGINT PRIMARY KEY AUTO_INCREMENT
- `name`: VARCHAR(255)
- `source_type`: VARCHAR(50) (Optional, e.g., 'online_marketplace', 'physical_store')
- `contact`: VARCHAR(255) (Optional, e.g., email, phone number)

## Tag Table (`Tag`)
- `tag_id`: BIGINT PRIMARY KEY AUTO_INCREMENT
- `name`: VARCHAR(255) UNIQUE
- `type`: ENUM ('manual', 'rule', 'ai')

## Merchant Tag Table (`Merchant_Tag`)
- `merchant_id`: BIGINT, FOREIGN KEY (references Merchant.merchant_id)
- `tag_id`: BIGINT, FOREIGN KEY (references Tag.tag_id)
- PRIMARY KEY (`merchant_id`, `tag_id`)

## Merchant Tag Log Table (`Merchant_Tag_Log`)
- `log_id`: BIGINT PRIMARY KEY AUTO_INCREMENT
- `merchant_id`: BIGINT, FOREIGN KEY (references Merchant.merchant_id)
- `tag_id`: BIGINT, FOREIGN KEY (references Tag.tag_id)
- `action`: VARCHAR(50) (e.g., 'added', 'removed')
- `operator_id`: BIGINT (ID of the user or system performing the action)
- `timestamp`: TIMESTAMP DEFAULT CURRENT_TIMESTAMP
- `source`: VARCHAR(50) (e.g., 'admin_panel', 'system_rule')

## Product Tag Table (`Product_Tag`)
- `product_id`: BIGINT, FOREIGN KEY (references Product.product_id)
- `tag_id`: BIGINT, FOREIGN KEY (references Tag.tag_id)
- PRIMARY KEY (`product_id`, `tag_id`)

## Listing Table (`Listing`)
- `listing_id`: BIGINT PRIMARY KEY AUTO_INCREMENT
- `product_id`: BIGINT, FOREIGN KEY (references Product.product_id)
- `platform_id`: VARCHAR(255) (Identifier for the external platform, e.g., 'ebay_US', 'rakuten_JP')
- `status`: VARCHAR(50) (e.g., 'active', 'inactive', 'error')
- `publish_time`: TIMESTAMP

## Audit Log Table (`Audit_Log`)
- `log_id`: BIGINT PRIMARY KEY AUTO_INCREMENT
- `timestamp`: TIMESTAMP DEFAULT CURRENT_TIMESTAMP
- `user_id`: BIGINT (ID of the user performing the action, can be null for system actions)
- `action`: VARCHAR(255) (Description of the action, e.g., 'create_product', 'update_price')
- `target_type`: VARCHAR(50) (e.g., 'Product', 'Merchant', 'Tag')
- `target_id`: BIGINT (ID of the entity being audited)
- `details`: TEXT (JSON or formatted text containing details of the change)
